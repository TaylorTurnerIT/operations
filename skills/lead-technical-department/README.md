# lead-technical-department

Taylor's skill for leading a department of technical teams: priorities, resources, review, and acceptance routing.

- `SKILL.md`: the general method.
- `references/`: host notes (T3 Code, GitHub Projects) and model tiers.
- `references/projects/`: one file per project (`mudcrab.md`, `dodge-native.md`) with boards, limits and user overrides.

Private. Lives in the `operations` repository. `~/.agents/skills/lead-technical-department` is a symlink to this folder.
